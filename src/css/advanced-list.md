# 高级技巧

| 属性              | 功能                                                   |
| ----------------- | ------------------------------------------------------ |
| `:has()`          | 父选择器，比如 div:has(img) 可以选中包含图片的 div。   |
| `:is()`           | 选择该列表中任意一个选择器可以选择的元素。             |
| `:where()`        | 将会选择所有能被该选择器列表中任何一条规则选中的元素。 |
| `:focus-within()` | 当元素或其任意后代元素被聚焦时，将匹配该元素。         |

## 属性

| 属性                       | 功能                                             |
| -------------------------- | ------------------------------------------------ |
| `scroll-behavior: smooth;` | 给 html 添加上可以实现 丝滑滚动效果。            |
| `text-wrap: balance;`      | 文字自动均匀换行，避免最后一行只有一个字的尴尬。 |

## 函数

| 属性          | 功能                                                  |
| ------------- | ----------------------------------------------------- |
| `color-mix()` | 颜色混合函数，动态生成 hover、disabled 等状态的颜色。 |

## 动画

| 属性                   | 功能                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| `view-transition-name` | 为选中的元素提供了一个独特的标识名称，并使其参与与根视图过渡分开的视图过渡。 |
